options Object Object with the following properties:
Name Type Description
heatmapoptions Object optional Optional heatmap.js options to be used (see http://www.patrick-wied.at/static/heatmapjs/docs.html#h337-create).
bounds Object optional The bounding box for the heatmap in WGS84 coordinates.
Name Type Description
north Number optional The northernmost point of the heatmap.
intensityScale Number optional 3d热力图的夸张系数，默认是0，大于0将启用3d热力图，等于0为2d热力图.
bounds.south Number optional The southernmost point of the heatmap.
bounds.west Number optional The westernmost point of the heatmap.
bounds.east Number optional The easternmost point of the heatmap.
data Object optional Data to be used for the heatmap.
Name Type Description
min Object optional Minimum allowed point value.
max Object optional Maximum allowed point value.
points Array optional The data points for the heatmap containing x=lon, y=lat and value=number.
